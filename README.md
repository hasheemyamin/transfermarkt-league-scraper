# Transfermarkt League Scraper

A Python project that scrapes football player profile data and market value history from Transfermarkt.

## What this project does
- Scrapes player profile data (name, club, position, nationality, age, height, agent)
- Collects current market value and full market value history
- Supports scraping entire leagues (Premier League, Serie A)
- Exports clean CSV files for analysis

## Tech stack
- Python
- requests
- BeautifulSoup
- pandas

## Notes
This project is for personal and educational use only.

## How to run

1. Install dependencies:

pip install -r requirements.txt

2. Run the scraper:

python main.py

##For testing, start with a small number of players to avoid long runtimes.
